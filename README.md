# LDIF Builder

Browser tools for preparing LDAP/OUD directory data: CSV ↔ LDIF conversion, attribute cleanup, and import error review. File contents stay in the browser.

## Develop

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
pnpm preview
```

## Deploy

See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Production URL: `https://trust.quivlabs.com`.
